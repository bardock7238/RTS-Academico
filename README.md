# RTS Académico

Proyecto en Unity para un juego de estrategia en tiempo real.

## Carpetas principales

- `Assets/Arte`: imágenes, modelos, animaciones, sonidos y prefabs que Unity usa.
- `Assets/Escenas`: escenas del juego.
- `Assets/Scripts`: código del juego.
- `Diseno`: bocetos y archivos de trabajo del diseñador. Unity no los importa automáticamente.

El proyecto usa Unity 6.0.6f1.
