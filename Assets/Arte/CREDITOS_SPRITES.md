# Créditos de sprites — `Assets/Arte/Texturas/`

Sprites pixel-art 16×16 descargados de fuentes libres para el RTS académico.
**OJO — licencias:** casi todo es CC0 (sin crédito obligatorio), pero el pack
de Toen exige atribución (ver abajo). Mantener este archivo con el proyecto.

## `TinyTown/` — CC0 (dominio público, crédito opcional)

- **Autor:** Kenney (https://kenney.nl)
- **Pack:** Tiny Town — 130+ PNG (tiles `tile_XXXX.png` de 16×16 + `Tilemap/`)
- **Uso:** edificios (casas, castillos, torres) y terreno del mapa.
- **Licencia:** Creative Commons Zero v1.0 Universal.
- Crédito opcional: "Kenney.nl" o "www.kenney.nl".

## `ToenMedieval/` — ⚠️ CC-BY 4.0 (ATRIBUCIÓN OBLIGATORIA)

- **Autor:** Andre Mari Coppola (https://twitter.com/ToenAndreMC)
- **Pack:** Toen's Medieval Strategy Sprite Pack v1.0 (16×16) — 308 gráficos:
  terreno, edificios (torres, pueblos, castillos, casas, ruinas), caminos,
  ríos, puentes, mar y sprites de GUI. Ver `Reference Sheet.png`.
- **Fuente:** https://opengameart.org/content/toens-medieval-strategy-sprite-pack-v10-16x16
- **Licencia:** Creative Commons Atribución 4.0 Internacional
  (http://creativecommons.org/licenses/by/4.0/).
- **Atribución exigida:** dar crédito al autor, enlazar la licencia e indicar
  si se modifica. Este archivo cumple el requisito de crédito.

## `PixelUI/` — CC0 (dominio público, crédito opcional)

- **Pack:** Pixel UI pack (750 assets) — botones (normal/pressed), paneles,
  barras, cursores en `9-Slice/` + hojas `Spritesheet`.
  (https://opengameart.org/content/pixel-ui-pack-750-assets)
- **Uso:** botones y paneles del HUD/menús.
- **Licencia:** Creative Commons Zero v1.0 Universal.
- En juego: `Resources/Sprites/UI/boton_{azul,verde,rojo,gris}` (+`_pulsado`).
